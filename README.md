# Uber Radius Overlay — Android 第一版

功能：在 Uber Driver 等其他 App 上方顯示一個紅色圓圈，半徑可輸入 0.1–20 km。

## 目前版本限制
第一版的紅圈是「螢幕中心固定圓圈」，**尚未做到地理座標與 Uber 地圖像素座標的校準**。因此畫面上的圓圈目前不是精確代表地圖上的 X 公里範圍。

下一版可以加入：GPS 中心、可拖曳中心、不同縮放倍率校準，以及「送完單後位置是否落在可接單區」的判斷。

## 建置
用 Android Studio 開啟本資料夾，讓 Gradle 同步後 Build APK。
需要授予：
- 顯示在其他 App 上層
- 精確定位

本工具不會自動點擊 Uber、不會自動接單。
